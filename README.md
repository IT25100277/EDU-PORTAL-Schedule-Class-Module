# EDU PORTAL — Schedule Class Module

### Software Engineering Group Project | SLIIT | 2026

## Project Overview

EDU PORTAL is a web-based Educational Institute Management System developed as part of our Software Engineering group project at SLIIT.

The system was developed by a six-member team to support educational institute management through integrated modules.

## My Contribution — Schedule Class Module

I was responsible for developing the Schedule Class module, including:

- Creating new class schedules
- Viewing existing class schedules
- Updating class schedule information
- Deleting class schedules
- Implementing form validations
- Integrating frontend and backend functionality
- Contributing to UML Activity and Sequence Diagrams

## Technologies Used

- Java
- Spring Boot
- React.js
- Microsoft SQL Server
- Git and GitHub

## Version Control & Collaboration

I developed my assigned module using a dedicated Git branch and contributed it to the shared project repository through a pull request.

My pull request, **Add schedule module #2**, was successfully merged into the team's master branch on October 7, 2026.
